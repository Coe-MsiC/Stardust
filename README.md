### A IDE for the osu! Framework

Stardust (or Stardust Engine) is a independent development environment (IDE) with gameengine like features made for developing a Osu! Framework game without any Issues.

## But what changes Stardust from other C# IDE's?
Stardust is made with developing in O!F in mind. It has a build in WYSIWYG screen and many gameengine like features while still supporting the core idea of being code first.
